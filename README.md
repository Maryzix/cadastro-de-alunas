## ⚙️ Funcionalidades atuais

### 👩‍🎓 Cadastro de alunas

É possível cadastrar uma aluna informando:

- Nome
- 3 notas

O sistema calcula automaticamente a média e informa se a aluna foi aprovada ou reprovada.

### 📋 Listagem

É possível visualizar todas as alunas cadastradas e suas respectivas médias.

### 🔎 Consulta de média

É possível pesquisar uma aluna pelo nome e consultar sua média e situação.

### 🛡️ Tratamento de erros

O sistema utiliza `try/catch` para tratar entradas inválidas, evitando que o programa seja encerrado inesperadamente.
